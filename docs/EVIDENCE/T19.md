# T19 — Partners, referral codes, commissions

Date: 2026-09-20

## Scope

Commission model on top of the T4P partners table: commission rules, commission
lines with state history, invoices/invoice-line tables (tables only), the
atomic commission-on-activation hook, Finance state actions, and the admin
partner directory. Real partnered activation stays gated on unresolved
OPEN_INPUTS (see Blockers).

## What was built

- **Schema** (`packages/db`, migration `0016_futuristic_marvel_zombies.sql`):
  `commission_rules` (fixed|percentage, value, currency, is_test,
  effective_from/to — SELECT/INSERT only), `commission_lines`
  (unique `(workspace_id, order_id)`, rule_snapshot JSONB, amount, currency,
  state, nullable invoice_id — SELECT/INSERT/UPDATE), `commission_line_events`
  (append-only history — SELECT/INSERT), `invoices` + `invoice_lines`
  (Phase A tables only). All workspace-scoped with the standard forced RLS
  tenant policy; grants enforce immutability.
- **Contracts** (`packages/contracts`): commission rule/snapshot, extended
  commission line, partner summary/detail (payout-gated), commission history,
  list/detail responses; client + endpoints + OpenAPI regenerated.
- **Backend** (`apps/backend/src/partners`): pure rule selection/amount/guard
  logic + `planCommissionForActivation`; the commission state machine; the
  `DatabaseCommissionActivationHook` wired into `DatabaseOrderTransitionStore`
  so a partnered order's activation and its single line commit in one
  transaction; `DatabasePartnerStore` (list/detail/state change); staff routes.
- **Admin** (`apps/admin`): `/w/[workspace]/partners` list and
  `/w/[workspace]/partners/[partnerId]` detail — referral codes, referred
  orders, commission lines + states, Finance carrier-paid action, disabled
  payout UI explaining the missing dependency. All via the backend.

## Invariants honoured

- Commission earned only on activation, exactly once (unique
  `(workspace_id, order_id)` + in-transaction insert), rule snapshotted.
- Rule change leaves earned lines untouched (superseding rule = new row).
- Commission state independent of order status (invariant 9).
- A TEST rule can never enter live records: barred under `NODE_ENV=production`.
- `partner_paid` disabled; percentage rules blocked pending OPEN_INPUTS #17.
- order.partner_id already copied from the lead at submission (T11/T12).
