# Evidence

Proof that a gate passed or a page matched its design. Each file or folder says what was
run, when, and what it showed; evidence never authorizes a production action by itself.

## Task and gate evidence

- `T*.md`, `T*.txt` — per-task verification from the build sequence (T1 scaffold, T1/T2
  review and local CI, T3 site-1 scaffold and security, T5 staff auth, T6 website
  credentials, T10/T12/T15 catalogue, orders and outbox, T13 order form, T14 admin order
  processing, T19 partners and commissions).
- `A0-recovery-spike.md`, `A1.md`, `A2.md`, `A4-accessibility.md`, `A4-restore.md` — the
  Phase A gate evidence (recovery feasibility, isolation and preview boundary, order journey
  and pricing integrity, accessibility and SEO, backup and restore rehearsal in an isolated
  harness).
- `T2-screenshots/`, `A2-screenshots/` — browser captures the admin and site-1 e2e suites
  refresh when `CAPTURE_SCREENSHOTS=1` is set.

## Per-page design verification

One folder per storefront page or page group (`home`, `pre-arrival`, `mobile-plans`,
`home-internet`, `plan-finder`, `pre-arrival-order`, `internet-order`, `track-order`,
`contact`, `faq`, `about`, `guides`, `guides-index`, `legal`, `system`, `emails`,
`shared-components`, `category-sim`, `category-rogers`, `category-internet`,
`category-airport-compare`, `category-review`). Each `README.md` names the Figma frames
read, the browser captures taken at 390 and 1440, and the checks recorded in
`verification.json` (headings, keyboard interaction, axe, image geometry).

## Storefront audits

- `audit/` — output of the `apps/site-1/scripts/audit-*.mjs` and `verify-*.mjs` scripts:
  `final/` (page captures, pixel diffs, focus and consent results), `final-verified/lighthouse/`
  (Lighthouse runs and summary), `review-baseline/` and `design-review-final/` (payload and
  visual comparisons for the design and code review), `category-final/` and
  `electric-blue-final/` (captures for the category templates and the Electric Blue
  redesign).
- `audit/page-audit-2026-10-13.md` — the 13 October 2026 page audit (performance,
  accessibility and metadata fixes; its table is regenerated by `audit-report.mjs`).
- `audit/design-code-review-2026-10-13.md` — the 13 October 2026 design and code review
  (39 route/state cases, fixes and payload measurements).
- `audit/codebase-audit-2026-10-22.md` — the 22 October 2026 read-only codebase audit
  (177 findings with IDs that later fix commits cite).
- `landing/` — captures from `verify-landing.mjs` for the seven SEO landing pages and
  `/about` after the Electric Blue redesign.
