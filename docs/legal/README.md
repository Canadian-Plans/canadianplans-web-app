# Published legal versions

The current release is **version 2, effective 21 October 2026**:

- [Privacy Policy](privacy-v2.md): customer records and accepted identity documents
  are retained until the customer requests deletion; no fixed deletion period.
- [Terms of Service](terms-v2.md): released with the updated privacy policy.

New static-catalogue quotes use `terms-2026-10-v2`; new lead and wish-list captures
record `privacy-2026-10-v2`. Existing order snapshots and accepted versions are
immutable. A CMS legal page is shown only when its version equals this release;
any other version (older or newer) falls back to the repo text. A new legal version
must ship together with the catalogue terms version and the site consent versions.

The version 1 files are historical records of the text previously accepted,
not the current retention policy. Keep them for version evidence; do not rewrite
an old accepted version when policy changes.
